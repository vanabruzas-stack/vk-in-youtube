# Референсы VK Видео

Положите материалы в эти папки:

- `vkvideo/site/` — главная, поиск, просмотр видео, канал, плейлист, подписки, история, клипы/Shorts, трансляции, настройки.
- `vkvideo/studio/` — Кабинет автора: Обзор, Мой контент, аналитика канала, аналитика видео, загрузка, комментарии, монетизация, настройки.

Для каждого экрана лучше сохранить:

1. Скриншот всей страницы и скриншот видимой области при ширине 1440 px (или укажите своё разрешение).
2. Если возможно, страницу через браузер «Сохранить как → Веб-страница полностью» — HTML вместе с папкой ресурсов. Можно также приложить отдельные CSS, шрифты и иконки.
3. По возможности состояния меню, фильтров, таблиц, графиков, форм и модальных окон. Для светлой и тёмной темы — отдельные снимки.

Называйте файлы по экрану, например `studio/overview-dark-1440x900.png`, `studio/content-menu.png`, `site/watch-light.png`. Рядом можно создать текстовый файл с URL, датой снимка, разрешением и примечаниями.

При сохранении страницы не прикладывайте cookies, токены, пароли, экспорт профиля браузера или личные данные канала, которые не хотите раскрывать. Скриншоты с реальными данными можно замазать, сохранив геометрию интерфейса.

**Приоритет для продолжения:** десктопные `studio/overview`, `studio/content`, `studio/analytics-channel`, `studio/analytics-video`, `studio/upload` и `site/home`, `site/watch`.
