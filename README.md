# VK Видео в YouTube

Расширение для Chrome и других браузеров Chromium оформляет YouTube и YouTube Studio в стиле VK Видео. Ролики, рекомендации, поиск, комментарии, загрузка и аналитика остаются функциями YouTube.

Обратное расширение для VK Видео теперь находится в [отдельном репозитории youtube-in-vk](https://github.com/vanabruzas-stack/youtube-in-vk).

## Установка · 1.0.15

- [Установщик Windows одним файлом](downloads/VK-YouTube-Setup-1.0.15.exe) — скачайте и запустите `.exe`. Он содержит расширение и работает без отдельного файла конфигурации.
- [ZIP расширения](downloads/vk-youtube-1.0.15.zip) — распакуйте, включите режим разработчика на `chrome://extensions` или `edge://extensions` и выберите «Загрузить распакованное расширение».

После обновления распакованной версии нажмите кнопку обновления на карточке расширения и обновите страницы YouTube и YouTube Studio.

## Возможности

- Шапка и меню VK Видео, сетка видео, страницы канала и просмотра, описание с раскрытием, история и список рекомендаций.
- Кабинет автора показывает данные YouTube Studio в оформлении VK Видео. Загрузка, аналитика и настройки используют действия YouTube.
- Поиск с видимой лупой: запрос можно отправить клавишей Enter или нажатием на значок. В версии 1.0.13 строка корректно обновляется при переходах между страницами.
- Штатный плеер YouTube сохраняет качество, скорость, субтитры, звуковые дорожки, «Постоянную громкость» (если её предлагает YouTube) и полноэкранный режим. Рамка плеера подстраивается под пропорции видео при изменении ширины меню.
- Описание оформлено единым блоком VK Видео и сохраняет раскрытое состояние при обновлении разметки YouTube.
- Ролики канала «РЫЖАЯ МОРДА» добавляются в локальную ленту и рекомендации, если каталог канала доступен. Увеличенные числа просмотров видны только пользователям расширения: реальные счётчики и алгоритм YouTube не меняются.
- Настройки расширения позволяют включать оформление сайта и студии отдельно.
