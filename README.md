# VK Видео в YouTube

Расширение для Chrome и других браузеров Chromium оформляет YouTube и YouTube Studio в стиле VK Видео. Ролики, рекомендации, поиск, комментарии, загрузка и аналитика остаются функциями YouTube.

Обратное расширение для VK Видео теперь находится в [отдельном репозитории youtube-in-vk](https://github.com/vanabruzas-stack/youtube-in-vk).

## Установка · 1.0.12

- [Установщик Windows](downloads/VK-YouTube-Setup-1.0.12.exe) и [файл конфигурации](downloads/VK-YouTube-Setup-1.0.12.exe.config) — скачайте оба файла в одну папку и запустите `.exe`.
- [ZIP расширения](downloads/vk-youtube-1.0.12.zip) — распакуйте, включите режим разработчика на `chrome://extensions` или `edge://extensions` и выберите «Загрузить распакованное расширение».

После обновления распакованной версии нажмите кнопку обновления на карточке расширения и обновите страницы YouTube и YouTube Studio.

## Возможности

- Шапка и меню VK Видео, сетка видео, страницы канала и просмотра, описание с раскрытием, история и список рекомендаций.
- Кабинет автора показывает данные YouTube Studio в оформлении VK Видео. Загрузка, аналитика и настройки используют действия YouTube.
- Поиск с видимой лупой: запрос можно отправить клавишей Enter или нажатием на значок. В версии 1.0.12 строка корректно обновляется при переходах между страницами.
- Штатный плеер YouTube сохраняет качество, скорость, субтитры, звуковые дорожки и полноэкранный режим.
- Настройки расширения позволяют включать оформление сайта и студии отдельно.
