# YouTube в интерфейсе VK Видео — установка

## Что готово

- Расширение Chrome Manifest V3 для `youtube.com` и `studio.youtube.com`.
- Оригинальные начертания VK Sans 400/500/600/700 встроены в расширение и устанавливаются вместе с ним.
- Используются SVG-иконки из открытого MIT-пакета `@vkontakte/icons`; установленный vidIQ не блокируется и получает совместимое тёмное оформление.
- Тёмная палитра, типографика и отдельная оболочка Studio по осмотренному кабинету VK Видео.
- Переключатели оформления сайта и Studio, отдельный переключатель панели статистики.
- В таблице Studio период по умолчанию — «Последние 7 дней». Показатели видимых роликов запрашиваются за выбранный период через официальный YouTube Analytics API; «За всё время» не берётся из накопленного счётчика строки.
- Кнопки навигации и загрузки в новой оболочке вызывают родные элементы YouTube Studio. Формы редактирования и загрузки остаются родными, поверх них применяется оформление.
- На главной сетка всегда по четыре карточки в ряд, как в VK Видео на обычном мониторе.
- Канал [РЫЖАЯ МОРДА](https://www.youtube.com/@%D0%A0%D0%AB%D0%96%D0%90%D0%AF%D0%9C%D0%9E%D0%A0%D0%94%D0%90) открывается только после удаления расширения. При установке лишняя вкладка не открывается.
- Главная, каналы, тренды, клипы, история и плейлисты используют живой DOM YouTube с бесконечной загрузкой. Ролики автора подмешиваются в рекомендации без отдельного раздела с названием канала.
- На своём канале и своих роликах показывается локальный шуточный буст статистики ×1000; реальные значения YouTube не изменяются.
- «Смотреть позже», «Мне понравилось» и плейлисты открываются той же сеткой VK, а не пустой родной страницей.
- На главной каждая карточка берёт свою обложку `hq720` по id ролика и живую аватарку канала, без букв-заглушек и повторов мини-картинок.
- Страница просмотра держит плеер 16:9 как в VK Видео, узкую колонку «Смотрите также» с родными разделами, синюю линию прогресса и скрывает дизлайк, мини-плеер и кинорежим.
- При входе на главную и во время видео иногда показывается тост «Применяются рекомендательные технологии», как в Юморде.
- YouTube Mix/«Джем» обозначается как «Плейлист» и показывается в компактном блоке над рекомендациями.
- Просмотр клипов использует вертикальный размер и отступы VK Видео; лишние действия Remix и аудиодорожки скрыты.
- Панель статистики показывает доступные показатели канала или отдельного видео и график по дням. При отсутствии доступа данные не выдумываются.

## Установка базового оформления

### Простой способ для Windows

1. Запустите `VK-YouTube-Setup.exe`, выберите браузер и нажмите синюю кнопку.
2. Установщик разложит расширение в `%LOCALAPPDATA%\VK Video for YouTube\Extension`, откроет страницу расширений браузера и выделит папку `Extension` в Проводнике.
3. Справа вверху включите «Режим разработчика».
4. Перетащите выделенную папку `Extension` в окно браузера. Если Chrome не принимает перетаскивание, нажмите «Загрузить распакованное» и выберите эту папку.

Chrome не разрешает обычной программе автоматически включить локальное расширение: это защита браузера. Установщик открывает нужную внутреннюю страницу через адресную строку, но включение режима разработчика и подтверждение папки нужно сделать один раз вручную. Для обновления запустите установщик снова и нажмите «Обновить» на карточке расширения.

### Ручной способ

Распакуйте `YouTube-VK-Video-extension.zip`, откройте страницу расширений браузера и загрузите папку как распакованное расширение Manifest V3.

Базовое оформление работает без Google Cloud. Статистика за выбранный период требует настройки OAuth.

## Подключение реальной статистики

1. Загрузите распакованное расширение и скопируйте его ID со страницы `chrome://extensions`.
2. В собственном проекте Google Cloud включите **YouTube Analytics API**. Создайте OAuth Client ID типа **Chrome Extension**, указав скопированный ID расширения. Секрет клиента расширению не нужен.
3. Распакуйте `YouTube-VK-Video-source.zip`, установите Node.js и выполните в PowerShell в корне проекта:

   ```powershell
   npm ci
   $env:YOUTUBE_OAUTH_CLIENT_ID = 'ВАШ_CLIENT_ID.apps.googleusercontent.com'
   npm run build
   ```

4. Замените содержимое установленной папки файлами из `dist`, нажмите «Обновить» на карточке расширения и в его меню выберите «Подключить статистику». Авторизуйте тот Google-аккаунт, который владеет нужным каналом.

Для API используются только разрешения чтения `yt-analytics.readonly` и `youtube.readonly`. OAuth Client ID нельзя угадать или заменить чужим: он привязан к ID установленного расширения. Официальные инструкции: [OAuth для Chrome Extensions](https://developer.chrome.com/docs/extensions/how-to/integrate/oauth), [YouTube Analytics reports.query](https://developers.google.com/youtube/analytics/reference/reports/query).

## Проверено и ограничения

- `npm run check`, `npm run build` и `npm test` проходят. Два браузерных теста проверяют оболочки YouTube и Studio, SPA-маршруты, реальные ссылки, вызов родных кнопок и смену статистического периода.
- Публичная главная YouTube проверена в Chrome без авторизации. В этом сеансе она показывала пустое состояние, поэтому карточки личных рекомендаций там проверить нельзя. Страницы каналов с обычными видео и клипами проверены на живом DOM YouTube: заголовки, обложки и аватары отображаются.
- Авторизованная вкладка YouTube Studio пользователя не появилась в доступном подключении `@Chrome`, хотя ссылка была передана. Поэтому визуальная точность, все формы загрузки/редактирования, видеоредактор и аналитика на реальном Studio **не проверены**. Версия 0.14.0 чинит сетку комментариев кабинета и расширяет эти экраны безопасными стилями поверх родного DOM, но это всё ещё не подтверждённое попиксельное воспроизведение.
- Статистика OAuth не проверена на живом аккаунте без OAuth Client ID. До его настройки расширение явно показывает отсутствие доступа; накопленные показатели родного Studio остаются видны.
- Реальные публикации, изменения настроек и удаления не выполнялись.

Структура и размеры осмотренного VK Видео сохранены в двух приложенных заметках об осмотре.
