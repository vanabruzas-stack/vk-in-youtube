# VK Видео в стиле YouTube

Отдельное расширение для Chrome и Edge. Оформляет `vkvideo.ru`, `live.vkvideo.ru` и `cabinet.vkvideo.ru` в стиле YouTube и YouTube Studio. Открытые ролики, статистика, комментарии, публикация и настройки остаются штатными функциями VK Видео.

## Установка

Самый простой способ в Windows: скачайте [установщик](../downloads/YouTube-for-VK-Setup-0.1.0.exe) и [файл конфигурации](../downloads/YouTube-for-VK-Setup-0.1.0.exe.config) в одну папку, запустите установщик и выполните показанные шаги Chrome или Edge.

Вручную: распакуйте [ZIP](../downloads/youtube-for-vk-0.1.0.zip), откройте `chrome://extensions` или `edge://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите распакованную папку. После установки обновите вкладки VK Видео.

Для сборки из исходников в корне репозитория выполните `npm install`, `npm run build:reverse`, `npm run test:reverse`. Результат: `reverse-extension/dist`.

В окне расширения можно отдельно выключить оформление основного сайта и кабинета автора. Первое расширение «YouTube в интерфейсе VK Видео» продолжает работать независимо.

## Область оформления

- Главная и сетка видео: верхняя панель, поиск, левое меню, карточки, длительность роликов.
- Просмотр, каналы, поиск и клипы: общая типографика, навигация, вкладки и кнопки. Плеер и полноэкранный режим использует сам VK.
- Отдельный сайт трансляций VK Видео Live: шапка, меню, поиск и карточки эфиров.
- Кабинет автора: шапка YouTube Studio, меню, обзор, таблица контента, аналитика, комментарии, настройки и модальные формы.
